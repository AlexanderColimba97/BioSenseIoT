════════════════════════════════════════════════════════════════════════════════════

Every 10 seconds:

┌────────────────────────────────────────────────────────────────────┐
│  ESP32 Main Loop                                                   │
│                                                                    │
│  1. Read Analog Values from Sensors                                │
│     ├─ MQ4 (CH4/Methane)    : GPIO 35 → ADC value 0-4095         │
│     ├─ MQ7 (CO)             : GPIO 34 → ADC value 0-4095         │
│     └─ MQ135 (CO2)          : GPIO 32 → ADC value 0-4095         │
│                                                                    │
│  2. Convert ADC to PPM (using calibration formulas)                │
│     ├─ calculatePPM(ADC, RL, R0, a, b)                            │
│     ├─ Voltage = (ADC / 4095) * 3.3V                              │
│     ├─ Rs = ((3.3 * RL) / Voltage) - RL                           │
│     ├─ Ratio = Rs / R0                                            │
│     └─ PPM = a * (Ratio)^b                                        │
│                                                                    │
│  3. Results Example:                                               │
│     ├─ MQ4:   ADC 1523 → 25.30 PPM                                │
│     ├─ MQ7:   ADC 892  → 8.50 PPM  (Normal, < 9ppm)               │
│     └─ MQ135: ADC 1234 → 450.00 PPM (Normal, < 1000ppm)           │
│                                                                    │
│  4. Evaluate Air Quality Risk Level                                │
│     ├─ if (MQ7 > 30) → DANGER (Red)                               │
│     ├─ else if (MQ7 > 9) → WARNING (Orange)                       │
│     └─ else → SAFE (Green)                                        │
│                                                                    │
│     Result: SAFE ✅                                               │
│                                                                    │
│  5. Update LED Indicator                                           │
│     ├─ digitalWrite(LED_GREEN, HIGH)   ← Turn ON                  │
│     ├─ digitalWrite(LED_ORANGE, LOW)   ← Turn OFF                 │
│     └─ digitalWrite(LED_RED, LOW)      ← Turn OFF                 │
│                                                                    │
│  6. Generate Unique Reading ID                                     │
│     └─ "AA:BB:CC:DD:EE:FF-156234"  (MAC-Millis)                   │
│                                                                    │
│  7. Check Deduplication Buffer                                     │
│     ├─ isDuplicateReading(readingId)?                              │
│     └─ No duplicates found ✅ → Continue                           │
│                                                                    │
│  8. Add to Deduplication Buffer                                    │
│     └─ addToBuffer(readingId, mq4, mq7, mq135)                    │
│                                                                    │
│  9. Create JSON Payload                                            │
│     {                                                             │
│       "macAddress": "AA:BB:CC:DD:EE:FF",                          │
