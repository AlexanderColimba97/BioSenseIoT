📋 CONFIGURACIÓN PASO A PASO
═══════════════════════════════════════════════════════════════════════════════

1. ABRE ARDUINO IDE

2. Instala el board manager de ESP32 (si no lo tienes):
   
   Tools → Board Manager
   Busca: "esp32"
   Instala: "esp32 by Espressif Systems" (versión 2.0.0+)

3. Selecciona el BOARD correcto:
   
   Tools → Board → esp32 → "ESP32 Dev Module"
   
   (Este es para el ESP32-32D N4)

4. Selecciona el PUERTO:
   
   Tools → Port → COM8
   
   ✅ Tu puerto es COM8

5. Configura los parámetros adicionales:
   
   Tools → Upload Speed → 921600 (rápido)
   Tools → Flash Frequency → 80 MHz
   Tools → Flash Mode → DIO
   Tools → Flash Size → 4MB (o detecta automáticamente)
   Tools → Partition Scheme → Default
   Tools → Core Debug Level → Info

❓ PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════════

❌ "Timed out waiting for packet header"
   
   SOLUCIÓN:
   1. Presiona BOOT + EN en la tarjeta
   2. Mantén BOOT presionado hasta que suba
   3. Intenta de nuevo

❌ "Board not found"
   
   SOLUCIÓN:
   1. Tools → Board Manager
   2. Instala ESP32 by Espressif Systems
   3. Reinicia Arduino IDE

❌ "Port COM8 not found"
   
   SOLUCIÓN:
   1. Desconecta USB del ESP32
   2. Espera 3 segundos
   3. Reconecta USB
   4. Verifica Tools → Port → COM8

❌ "Serial Monitor vacío"
   
   SOLUCIÓN:
   1. Verifica velocidad: 115200 baud
   2. Presiona EN en la tarjeta
   3. Verifica que biosense_esp32_SECURE.ino está correcto

🎯 MODELO ESP32-32D N4 - ESPECIFICACIONES
═══════════════════════════════════════════════════════════════════════════════

Microcontrolador:    ESP32 (Dual Core Xtensa 32-bit)
Velocidad:           240 MHz
RAM:                 520 KB SRAM
Flash:               4 MB (16 MB en algunas versiones)
WiFi:                802.11 b/g/n
Bluetooth:           BLE 4.2 + BR/EDR
USB-UART Bridge:     CH340 (COM8 en tu PC)
Pines GPIO:          34 (algunos ADC, algunos con pull-up)
ADC:                 2 canales de 12-bit
SPI:                 HSPI + VSPI
I2C:                 2 canales
UART:                3 canales
Entrada tensión:     5V USB o 3.3V direct
Corriente max:       ~500mA (USB)
