✅ OPTIMIZACIONES IMPLEMENTADAS:
═══════════════════════════════════════════════════════════════════════════════

1️⃣  ELIMINADAS librerías no esenciales:
    ❌ ArduinoJson (pesada: ~300KB)    → Reemplazada con JSON manual
    ❌ mbedtls (pesada: ~200KB)        → Comentada (se añade después)
    ✅ Ahorro estimado: ~500KB

2️⃣  REEMPLAZADO ArduinoJson con construcción manual de JSON:
    
    Antes (ArduinoJson):
    ───────────────────
    StaticJsonDocument<256> doc;
    doc["macAddress"] = macAddress;
    serializeJson(doc, jsonPayload);
    
    Ahora (Manual):
    ───────────────
    String jsonPayload = "{\"macAddress\":\"" + macAddress + ..."}";
    
    ✅ Ahorro: ~150KB de código compilado

3️⃣  CONFIGURACIÓN COMPILER OPTIMIZADO:
    
    Las optimizaciones se aplican automáticamente en Arduino IDE:
    • -Os (Optimize for Size)
    • Strip unused functions
    • Link-time optimization
