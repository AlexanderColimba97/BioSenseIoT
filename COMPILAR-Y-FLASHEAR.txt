OPCIÓN 1: ARDUINO IDE (RECOMENDADO - MÁS FÁCIL)
═══════════════════════════════════════════════════════════════════════════════

Requisitos:
  ✓ Arduino IDE 1.8.13+ instalado
  ✓ Tarjeta ESP32 instalada (Tools → Board Manager → esp32)
  ✓ Librerías instaladas:
    - WiFi (incluida)
    - HTTPClient (incluida)
    - ArduinoJson (Tools → Manage Libraries → busca "ArduinoJson")

Pasos:

1. Abre Arduino IDE

2. Archivo → Abrir
   Navega a: C:\Users\alexi\Desktop\BioSenseIoT\hardware\esp32_biosense
   Selecciona: biosense_esp32_SECURE.ino

3. Tools → Board → ESP32 Dev Module

4. Tools → Port → COM3 (o tu puerto - ej: COM4, COM5)
   (Si no ves el puerto, revisa el Administrador de dispositivos)

5. Verifica que compila (sin errores):
   Sketch → Verify (Ctrl+R)
   Espera mensaje: "Sketch uses X bytes... Compilation complete."

6. Si todo está OK, flashea:
   Sketch → Upload (Ctrl+U)
   Espera mensaje: "Hard resetting via RTS pin..."

7. Abre Serial Monitor:
   Tools → Serial Monitor (Ctrl+Shift+M)
   Velocidad: 115200 baud

8. Busca estos mensajes:
   ✅ "Iniciando BLE..."
   ✅ "WiFi conectado"
   ✅ "📤 Enviando datos al backend (SEGURO)..."
   ✅ "✅ Datos guardados correctamente en la BD!"

SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

❌ ERROR: "Board ESP32 not found"
   SOLUCIÓN:
   - Arduino IDE: Tools → Board Manager → Busca "esp32" → Instala
   - PlatformIO: pio platform install espressif32

❌ ERROR: "Serial port COM3 not found"
   SOLUCIÓN:
   - Conecta ESP32 con cable USB
   - Abre Administrador de dispositivos (Win+R → devmgmt.msc)
   - Busca "ESP32" o "USB Serial Port"
   - Anota el número COM (ej: COM4)
   - Actualiza en Arduino IDE: Tools → Port → COM4

❌ ERROR: "Compiling sketch... error"
   SOLUCIÓN:
   - Verifica que ArduinoJson está instalada
   - Arduino IDE: Tools → Manage Libraries → ArduinoJson
   - Reinicia Arduino IDE
   - Intenta de nuevo

❌ ERROR: "Failed to upload"
   SOLUCIÓN:
   - Espera 10 segundos después de conectar
   - Intenta presionar BOOT + EN en la tarjeta
   - Intenta con puerto diferente
   - Reinstala drivers: https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-guides/dfu.html

❌ Serial Monitor: "No messages appearing"
   SOLUCIÓN:
   - Verifica velocidad: 115200 baud
   - Desconecta y reconecta USB
   - Presiona EN en la tarjeta
   - Verifica que biosnese_esp32_SECURE.ino está correcto
