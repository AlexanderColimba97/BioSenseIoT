🎯 THREE SACRED RULES (MEMORIZE THESE!)
═══════════════════════════════════════════════════════════════════════════════

Rule 1: AUTHENTICATE CORRECTLY
── User authentication: JWT (email + password)
── Device authentication: JWT (deviceId + deviceSecret)
── NEVER mix them
── NEVER use API keys

Rule 2: TRUST ONLY THE SERVER
── deviceId ALWAYS from JWT (server knows what device this is)
── deviceId NEVER from request body (attacker could forge it)
── Extract on server, validate always
── Reject any code that violates this

Rule 3: KEEP LAYERS CLEAN
── Controller: Routing only
── Service: Business logic
── Repository: Database access
── NO mixing, NO shortcuts
── ALWAYS maintain separation
