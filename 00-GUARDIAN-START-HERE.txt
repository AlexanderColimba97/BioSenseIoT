🎯 THREE SACRED RULES (ENFORCED BY GUARDIAN)
═══════════════════════════════════════════════════════════════════════════════

Rule 1: AUTHENTICATE CORRECTLY
  ✅ User JWT (email + password) ≠ Device JWT (deviceId + deviceSecret)
  ✅ NEVER use API keys (X-BioSense-Key is forbidden)
  ✅ ALWAYS use Bearer token authentication

Rule 2: TRUST ONLY THE SERVER
  ✅ deviceId ALWAYS from JWT (extracted server-side)
  ✅ deviceId NEVER from request body (prevent forgery)
  ✅ Validate on every request

Rule 3: KEEP LAYERS CLEAN
  ✅ Controllers: Route HTTP requests only
  ✅ Services: Business logic only
  ✅ Repositories: Database access only
  ✅ NO shortcuts, NO mixing
