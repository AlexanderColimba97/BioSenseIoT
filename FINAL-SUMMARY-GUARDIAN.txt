🎯 THREE SACRED RULES (Memorize Immediately)
───────────────────────────────────────────────────────────────────────────────

  1️⃣  AUTHENTICATE CORRECTLY
      User JWT ≠ Device JWT | NEVER API keys | ALWAYS Bearer token

  2️⃣  TRUST ONLY THE SERVER
      deviceId from JWT only | NEVER from request | Server is truth

  3️⃣  KEEP LAYERS CLEAN
      Controllers: Route | Services: Logic | Repositories: Data
      No shortcuts, No mixing, No exceptions
