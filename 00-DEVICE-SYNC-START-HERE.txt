🔄 COMPLETE SYNC FLOW (FIXED)
═══════════════════════════════════════════════════════════════════════════════

1. User powers on ESP32 (no WiFi saved)
   └─ ESP32 enters BLE mode

2. User scans Bluetooth from app
   └─ Frontend finds BioSense-[MAC]

3. User enters device name + WiFi credentials
   └─ Frontend reads MAC via BLE

4. User clicks "SINCRONIZAR"
   └─ Frontend POST /api/v2/devices/link (with User JWT)
   └─ Backend: Create device, generate apiSecret, link to user_id
   └─ Response: { deviceId, apiSecret } ← NEW

5. Frontend sends credentials via BLE
   └─ BLE Write: "SSID,PASSWORD,apiSecret"

6. ESP32 receives BLE data
   └─ Parse, store to NVS, restart

7. ESP32 connects to WiFi
   └─ Load NVS, initiate connection

8. ESP32 sends sensor data
   └─ Every 10 seconds: POST /api/v2/sensors/reading
   └─ Header: X-BioSense-Key: [apiSecret]
   └─ Backend: Validate device is linked, save reading

9. Frontend displays data
   └─ GET /api/v2/devices/my-devices
   └─ Shows device with readings
